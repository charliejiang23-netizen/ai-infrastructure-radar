## 持续更新说明

本项目将持续更新项目资料与来源核验记录。每次更新保留核查日期、依据和不确定性；没有公开证据的字段不补造数字。已安排 Codex 每天北京时间 09:00 核查；有可靠新证据时更新并发布。定时任务依赖 Codex 执行环境、网络与有效 GitHub 身份，无新证据不改数字。向 main 分支推送更新后，GitHub Pages 自动重新发布网页。

## 数据口径

H100e 为等效算力，不是实体 GPU 数量。规划、设计、受电与实际运营容量不可混为一谈；研究模型估算不视为官方实测。拥有多个链接不代表多个独立信源。公司客户关系不能直接推定单园区芯片所有权。

`data.js` 保留历史原始记录，必须结合 `data-revisions.js` 与 `evidence.js` 的更正使用。网页和 `docs/datacenter-source-audit.json` 展示更正后的资料。

## 本地运行

```sh
python -m http.server 8088
```

打开 http://localhost:8088/ 。新增项目保存在当前浏览器本地，只有提交到仓库的数据才会公开同步。
